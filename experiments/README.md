# Experiments

These are demonstrations and retained research, not dependencies of the
Forge3D production pipeline.

## `threejs/`

Fast prompt-authored procedural scenes used to evaluate Three.js modelling and
GLB export. Each demonstration is self-contained.

## `triposplat/`

TripoSplat viewing, Blender import, and mesh-conversion research. The retained
mesh comparison documents why direct splat-to-mesh reconstruction is not an
accepted production route; Gaussian splats remain the image-faithful static
visual route.

Generated dependencies, caches, logs, and build output remain ignored.
